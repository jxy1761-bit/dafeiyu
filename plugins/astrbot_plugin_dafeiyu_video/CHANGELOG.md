# 更新日志

## v0.4.0 — 2026-11-03
- 加第三条语音识别路线：小米 MiMo（`mimo-v2.5-asr`）。key 直接借 AstrBot 里「小米」那家服务商的，不另存一份。
- 顺序变成「本机识别（免费）→ 小米 MiMo → 硅基流动 key」，哪一步失败自动换下一个，全失败就只看画面。
- 新配置：`mimo_asr`（默认开）、`mimo_asr_model`（默认 `mimo-v2.5-asr`）、`mimo_first`（默认关，打开就让小米优先）。
- 小米这条路不用装任何东西，mp3/wav 都能直接认（11-03 实测 0.6 秒认完一句话，标点自己补）。

## v0.3.1 — 2026-11-02
- 视频：ffmpeg 均匀截帧给模型看，私聊都看、群里 @ 才看。
- 声音：本机 ASR 或硅基流动 key 转写，视频音轨和 QQ 语音都覆盖。
- `keep_frames` 控制截出来的画面是否留在聊天记录里。
